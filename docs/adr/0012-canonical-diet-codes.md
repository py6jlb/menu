# Канонические коды стандартных диет

Диета рецепта — свободный набор меток (`Recipe.Diet`), но известные стандартные диеты (вегетарианское, безглютеновое, постное, кетогенное) имеют канонический код (`vegetarian`, `gluten_free`, `lean`, `keto`) и русскую подпись для формы. Форма, жёсткие фильтры и мягкие предпочтения подбора работают с одним смыслом значения: известные варианты — код, русская подпись и частые словоформы — канонизируются, неизвестные метки сохраняются как есть.

Канонизация выполняется на записи (рецепт хранит код), на чтении (старые рецепты и живой контент внешнего источника показываются кодом, но источник не перезаписывается) и в подборе (сравнение идёт по каноническим значениям). Произвольная метка не переводится «по догадке» и не удаляется: пользователь может хранить свои диеты рядом со стандартными. Нормализация идемпотентна, поэтому повторное сохранение не порождает дублей.

Выбрали свободный набор с канонизацией вместо жёсткого справочника, потому что диет больше и они разнообразнее единиц измерения, а старые данные и внешние источники нельзя молча переписать. Единый `DietCatalog` — источник правил для записи, чтения и подбора.
