# Внешние рецепты — чтение между семьями через ссылку

Рецептом можно поделиться между семьями ссылкой `/r/{token}`: участник семьи-источника создаёт ссылку (`RecipeShare`, одна на рецепт), а получатель добавляет себе «внешний рецепт» — строку `Recipe` со ссылкой на источник (`SourceRecipeId`, `SourceFamilyId`, `SourceToken`). Контент читается живьём из семьи-источника, кэшируется только имя; правки источника видны получателю при каждом чтении. Граница владения из ADR-0001 не двигается: рецепт остаётся у семьи-источника, внешний рецепт — только чтение.

Внешний рецепт нельзя редактировать, удалять обычным способом и шарить дальше (`403`). Чтобы сохранить рецепт себе и править, его «промоутируют в копию» (`POST /api/recipes/{id}/copy`): внешний рецепт на месте превращается в обычный редактируемый рецепт (id и записи плана сохраняются), контент и файл фото копируются, метка «скопировано из семьи X» остаётся. Убрать внешний рецепт локально можно без затрагивания источника (`DELETE /api/recipes/{id}/external`); обычный `DELETE` на внешний рецепт не действует.

Ссылку владелец семьи может отозвать (новые добавления невозможны, существующие внешние рецепты продолжают читать контент) или перегенерировать (старый токен мёртв, выдаётся новый). Состояние внешнего рецепта получатель вычисляет по единому правилу «токен внешнего рецепта ≠ текущий токен шеринга, или шеринг отозван, или источник удалён»: «отозванная ссылка» (`state=warning` — источник жив, данные ещё можно спасти копией) и «сломанная ссылка» (`state=broken` — источник удалил рецепт: контент недоступен, остаётся кэш имени, рецепт исключается из списка покупок). Активных уведомлений о смене состояния нет — только пассивные предупреждения в UI.

Отвергли копирование при добавлении: копия разрывала бы связь с источником и требовала синхронизации. Ссылка с живым контентом держит рецепт актуальным ценой того, что он может «сломаться» при удалении источника; поэтому предусмотрены явный промоушен в копию и локальное удаление внешнего рецепта. Транзитивный шаринг и множественные ссылки на рецепт — вне MVP.
