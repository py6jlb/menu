# Справочник единиц и группы единиц

Ингредиент указывает количество числом и единицей из жёсткого справочника (`g, kg, ml, l, pcs, glass, tbsp, tsp, pinch`), а не свободным текстом. Единицы делятся на группы (вес, объём, штуки, бытовые); конвертация и объединение в списке покупок выполняются только внутри групп веса и объёма.

Выбрали фиксированный справочник вместо полного каталога продуктов, потому что он даёт корректную конвертацию и объединение при малой стоимости. Полный справочник продуктов вынесен за рамки MVP. Группы единиц — самостоятельное доменное понятие: они решают, объединять ли позиции, и это нельзя вывести из одной лишь единицы.
