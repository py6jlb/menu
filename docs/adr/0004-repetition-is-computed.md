# Повторяемость — вычисляемый признак, не хранится

Повторяемость рецепта (в скольких различных неделях окна он стоял в плане; повторения внутри одной недели дают один вклад) не сохраняется в БД, а вычисляется по записям планов за запрошенный диапазон. Окно задаётся в личных настройках пользователя (по умолчанию 3 недели). При подборе для конкретной недели окно заканчивается выбранной неделей включительно; в остальных чтениях — текущей неделей. Считаются только сохранённые планы.

Хранение отдельного счётчика отвергли: повторяемость всегда выводима из уже существующих планов, а хранимое значение устаревало бы при каждом изменении плана. Цена — пересчёт при каждом запросе, приемлемая для объёмов данных MVP.
