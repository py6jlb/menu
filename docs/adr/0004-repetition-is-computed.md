# Повторяемость — вычисляемый признак, не хранится

Повторяемость рецепта (сколько раз он готовился за окно недель) не сохраняется в БД, а вычисляется по записям планов за запрошенный диапазон. Окно задаётся в личных настройках пользователя (по умолчанию 3 недели).

Хранение отдельного счётчика отвергли: повторяемость всегда выводима из уже существующих планов, а хранимое значение устаревало бы при каждом изменении плана. Цена — пересчёт при каждом запросе, приемлемая для объёмов данных MVP.
