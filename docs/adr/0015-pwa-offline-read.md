# PWA: установка, офлайн-оболочка и офлайн-чтение

Приложение — устанавливаемый PWA: Web App Manifest (standalone, «Меню», кремовый theme/background) и service worker (`vite-plugin-pwa`, `generateSW`), который прекэширует оболочку и локально хостимый шрифт Nunito. Офлайн-чтение обеспечивает runtime-кэш читающих GET по стратегии network-first с fallback; обновление версии применяется по запросу, а не молча. Push-уведомлений нет.

Кэшируется явный allowlist читающих эндпоинтов: список покупок, план, рецепты (список и деталь), семья, настройки, автодополнение и публичный просмотр по ссылке. Аутентификация, админка и управление ссылками исключены. Лимиты runtime-кэша — 50 записей / 7 дней, `cleanupOutdatedCaches` убирает хвосты после деплоя. Кэш данных чистится при выходе и при `401`: устройство может быть общим. Офлайн-UI честно сообщает состояние баннером «нет сети» и пометкой «данные на момент последнего просмотра»; правки не ставятся в очередь, а падают на обычной обработке сетевых ошибок.

Выбрали офлайн-чтение, а не полный офлайн с синхронизацией: список покупок в магазине — главный сценарий, а очередь изменений потянула бы разрешение конфликтов ревизий и отдельную подсистему синхронизации. Обновление по запросу выбрано, потому что молчаливая подмена версии и ассетов опаснее лишнего клика. Шрифт хостится локально (`@fontsource`), чтобы офлайн не зависел от внешнего CDN.
