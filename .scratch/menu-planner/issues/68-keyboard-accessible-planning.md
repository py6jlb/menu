# 68: Планирование и формы, доступные с клавиатуры

**What to build:** Пользователь без мыши и со screen reader может выбрать блюдо, задать порции и фильтры, сохранить план и заполнить рецепт; диалог и сообщения дают понятный контекст и не теряют фокус.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Полный сценарий открыть запись плана → выбрать блюдо → порции → подтвердить → сохранить доступен через Tab/Enter и ожидаемые клавиши выбора.
- [ ] Выборы и удаление используют семантические элементы; нет кликабельного нефокусируемого li/span и вложенных друг в друга кнопок.
- [ ] Dialog имеет доступное имя, переводит фокус внутрь, удерживает его при модальности, поддерживает Escape и возвращает фокус к вызвавшему действию.
- [ ] Сезоны/диеты и другие checkbox доступны клавиатуре и accessibility tree; визуальное скрытие не удаляет их функциональность.
- [ ] Поля ингредиентов/шагов, перестановка и мобильный выход имеют однозначные доступные имена; исправлены вложенные label.
- [ ] Screen reader понимает день, приём пищи, выбранное блюдо, ошибку и успешный результат; live-объявления применены по назначению, без чрезмерного шума.
- [ ] Сохранены тёплая палитра, мобильная компоновка и размеры целей; нет горизонтального переполнения на согласованной минимальной ширине.
- [ ] Проверен клавиатурный сквозной сценарий и доступность ключевых имён/фокуса; изменения не требуют глобального редизайна.
