# 68: Планирование и формы, доступные с клавиатуры

**What to build:** Пользователь без мыши и со screen reader может выбрать блюдо, задать порции и фильтры, сохранить план и заполнить рецепт; диалог и сообщения дают понятный контекст и не теряют фокус.

**Blocked by:** None (can start immediately)

**Status:** resolved (ticket/68-keyboard-accessible-planning; commits 5b421ba, 24d203f; merge ee58ad8)

- [x] Полный сценарий открыть запись плана → выбрать блюдо → порции → подтвердить → сохранить доступен через Tab/Enter и ожидаемые клавиши выбора.
- [x] Выборы и удаление используют семантические элементы; нет кликабельного нефокусируемого li/span и вложенных друг в друга кнопок.
- [x] Dialog имеет доступное имя, переводит фокус внутрь, удерживает его при модальности, поддерживает Escape и возвращает фокус к вызвавшему действию.
- [x] Сезоны/диеты и другие checkbox доступны клавиатуре и accessibility tree; визуальное скрытие не удаляет их функциональность.
- [x] Поля ингредиентов/шагов, перестановка и мобильный выход имеют однозначные доступные имена; исправлены вложенные label.
- [x] Screen reader понимает день, приём пищи, выбранное блюдо, ошибку и успешный результат; live-объявления применены по назначению, без чрезмерного шума.
- [x] Сохранены тёплая палитра, мобильная компоновка и размеры целей; нет горизонтального переполнения на согласованной минимальной ширине.
- [x] Проверен клавиатурный сквозной сценарий и доступность ключевых имён/фокуса; изменения не требуют глобального редизайна.

## Evidence

- **Диалог**: `frontend/src/composables/useDialog.js` (+ `useDialog.test.js`, 11 тестов) — перевод фокуса внутрь при открытии, удержание на Tab/Shift+Tab, Escape, возврат фокуса к вызвавшему действию. Разметка пикера в `PlanView.vue` получила `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, `tabindex="-1"`.
- **Семантика выбора и удаления**: варианты подбора — `<button>` с `aria-pressed`, кнопка удаления записи вынесена из кнопки-ячейки в соседнюю подписанную кнопку; ячейки получили `aria-label` с днём, приёмом пищи, блюдом, порциями и состоянием.
- **Checkbox сезонов/диет**: `display: none` заменён на `.sr-only` (глобальный в `App.vue`); чипы получают видимый фокус через `:has(input:focus-visible)`.
- **Имена полей**: ингредиенты/шаги, перестановка и удаление получили уникальные `aria-label`; автодополнение ингредиентов оформлено как `combobox`/`listbox` с `aria-activedescendant`; вложенные `<label>` в формах входа/регистрации/восстановления заменены на `<span>`; мобильная кнопка выхода получила `aria-label`.
- **Live-регионы**: успех — `role="status"`, ошибки действий — `role="alert"`; пустая выдача подбора — `role="status"`.
- **Проверка**: `cd frontend && npm test` — 200 тестов зелёные; `npm run build` — успешно.
