# 26: Просмотр рецепта по ссылке

**What to build:** По ссылке `/r/{token}` любой человек (без входа) открывает страницу и видит живой рецепт семьи-источника: название, описание, шаги, ингредиенты с единицами и примечаниями, порции, время, сложность, калорийность, теги, сезонность, диету, фото. Правки источника сразу видны. Мёртвый или отозванный токен → «Ссылка недействительна».

**Blocked by:** 25 (Шаринг рецептом по ссылке)

**Status:** ready-for-agent

- [ ] `GET /api/shared/{token}` без авторизации возвращает живой полный рецепт из семьи-источника (все поля + `photoUrl`)
- [ ] Изменения источника (название, ингредиенты, шаги, порции, фото) видны при повторном открытии
- [ ] Несуществующий или отозванный токен → «Ссылка недействительна» (не раскрывает содержимого)
- [ ] Страница `/r/{token}` на фронте показывает рецепт только для чтения; для неавторизованного — приглашение войти
- [ ] Flow-тесты через `ApiFactory` покрывают анонимный просмотр, живое обновление и мёртвый токен
