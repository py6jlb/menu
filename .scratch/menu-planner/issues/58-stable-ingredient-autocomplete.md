# 58: Автодополнение ингредиентов со стабильными строками

**What to build:** Пользователь быстро вводит и переставляет ингредиенты, не получая подсказки для другой строки или предыдущего текста; удалённая строка и закрытый список не оживают после позднего ответа.

**Blocked by:** None (can start immediately)

**Status:** resolved (ticket/58-stable-ingredient-autocomplete; commit f866bef)

- [x] Строка ингредиента имеет стабильную локальную identity, независимую от её индекса; таймеры и requests принадлежат этой identity.
- [x] Debounce и результат проверяют актуальные строку, query и request generation; ответ старого текста не заменяет более новый.
- [x] Blur, выбор подсказки и Escape закрывают список; уже отправленный ответ не открывает его заново без актуального действия пользователя.
- [x] Удаление и перестановка строк во время ожидания безопасны, таймер не обращается к другой/отсутствующей строке.
- [x] Смена редактируемого рецепта и уход со страницы очищают таймеры и обезвреживают поздние ответы.
- [x] Network error снимает загрузку подсказок и не препятствует ручному вводу ингредиента; клавиатурный выбор сохраняет корректность.
- [x] Управляемые проверки покрывают быстрый набор, обратный порядок ответов, удаление соседней строки, перестановку, blur и выбор во время запроса.

## Evidence

- Новая композабл `frontend/src/composables/useIngredientAutocomplete.js` держит одну запись на строку по её стабильному `uid`: `{ state, timer, token, query }`. Дебаунс и запрос привязаны к `uid`, каждый ввод/закрытие/удаление выдаёт новый токен, а результат принимается только если токен и query всё ещё актуальны. `reset()` очищает таймеры и обезвреживает поздние ответы при смене рецепта и уходе со страницы.
- `draftFromRecipe`/`newIngredientDraft` (`useRecipeDraft.js`) присваивают строкам ингредиентов локальный `uid`, не участвующий в `serializeDraft` и `draftToPayload` (не влияет на dirty и не уходит на сервер).
- `RecipeFormView.vue` переведён на композабл: `:key="ing.uid"`, `@input`/`@blur`/keydown работают с объектом строки, а замена черновика (загрузка/сохранение) сбрасывает состояние автодополнения.
- Тесты: `useIngredientAutocomplete.test.js` — 15 проверок (быстрый набор, обратный порядок ответов, удаление соседней строки, перестановка, blur/выбор во время запроса, сетевой отказ, «нет подсказок», очистка); `useRecipeDraft.test.js` — identity ингредиентов не участвует в dirty и в payload. Полный frontend-suite: 105 тестов, `npm run build` проходит.
