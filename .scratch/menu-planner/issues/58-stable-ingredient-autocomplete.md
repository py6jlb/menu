# 58: Автодополнение ингредиентов со стабильными строками

**What to build:** Пользователь быстро вводит и переставляет ингредиенты, не получая подсказки для другой строки или предыдущего текста; удалённая строка и закрытый список не оживают после позднего ответа.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Строка ингредиента имеет стабильную локальную identity, независимую от её индекса; таймеры и requests принадлежат этой identity.
- [ ] Debounce и результат проверяют актуальные строку, query и request generation; ответ старого текста не заменяет более новый.
- [ ] Blur, выбор подсказки и Escape закрывают список; уже отправленный ответ не открывает его заново без актуального действия пользователя.
- [ ] Удаление и перестановка строк во время ожидания безопасны, таймер не обращается к другой/отсутствующей строке.
- [ ] Смена редактируемого рецепта и уход со страницы очищают таймеры и обезвреживают поздние ответы.
- [ ] Network error снимает загрузку подсказок и не препятствует ручному вводу ингредиента; клавиатурный выбор сохраняет корректность.
- [ ] Управляемые проверки покрывают быстрый набор, обратный порядок ответов, удаление соседней строки, перестановку, blur и выбор во время запроса.
