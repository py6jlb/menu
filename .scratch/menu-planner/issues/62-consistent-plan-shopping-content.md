# 62: Согласованные план и список покупок с диагностикой полноты

**What to build:** Семья видит одинаковое актуальное состояние блюда в плане и покупках; если продукты для части записей нельзя рассчитать, список честно сообщает об этом и позволяет перейти к замене блюда.

**Blocked by:** 60 — Единое актуальное чтение рецепта для списка и деталей.

**Status:** ready-for-agent

- [ ] План и покупки получают контент/state из единого модуля; для имени плана не загружаются все шаги, для покупок запрашиваются нужные ингредиенты/порции.
- [ ] Живые ингредиенты и servings источника используются для внешнего рецепта; warning продолжает участвовать в расчёте.
- [ ] Broken исключён из сумм, но возвращается в диагностике полноты с указанием записи плана и причины; устаревшие ингредиенты не подставляются.
- [ ] Экран покупок показывает предупреждение о неполном расчёте, перечень исключённых записей и переход к выбранной неделе для замены/удаления.
- [ ] Отсутствующий план, пустой план и план только с недоступными блюдами различимы для пользователя; обычный пустой результат не маскирует потерю источников.
- [ ] Количества, масштабирование, группировка единиц и отдельные бытовые меры сохраняют принятые правила без нового округления.
- [ ] Загрузка/смена недели в покупках игнорирует старый ответ, сетевые ошибки снимают pending и оставляют доступный предыдущий результат с понятной актуальностью.
- [ ] Проверены смешанный own/warning/broken план, изменение servings источника, удаление источника, пустые состояния и обратные ответы на разных неделях.
