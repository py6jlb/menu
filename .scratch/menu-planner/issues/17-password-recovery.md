# 17: Восстановление пароля (бэкенд)

**What to build:** Backend-поток восстановления пароля через forgot. `/forgot` ввод email → универсальный нейтральный ответ «если аккаунт существует и почта подтверждена, отправлен код» (не раскрывает существование/статус). Код сброса шлём только если аккаунт существует и почта подтверждена. Один запрос сброса: код + новый пароль + повтор (одна форма). Resend — те же правила (таймер 5 мин, универсальный ответ). Смена пароля инкрементирует `TokenVersion`, старые JWT → 401. Rate limit 5/час на email + на IP.

**Blocked by:** 12 (Миграция на .NET 10), 14 (Модель AuthCode и поля User), 15 (Подтверждение почты (бэкенд))

**Status:** ready-for-agent

- [ ] `POST /api/auth/forgot` — универсальный ответ, отправка кода только при подтверждённом email
- [ ] Сброс по коду: код + новый пароль + повтор (одна форма)
- [ ] Инвалидация сессий: инкремент `TokenVersion`, старые JWT → 401
- [ ] Resend на forgot с таймером (5 мин, настраивается) и универсальным ответом
- [ ] Rate limit: 5/час на email + на IP
- [ ] Интеграционные тесты восстановления
