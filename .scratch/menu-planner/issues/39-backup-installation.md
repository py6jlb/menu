# 39: Работающая установка резервного копирования

**What to build:** Оператор на чистом сервере по инструкции устанавливает ежедневное резервное копирование, запускает его от правильного пользователя и получает удалённую копию, а сбой установки или копирования заканчивается явным неуспехом.

**Blocked by:** 36 — Единый безопасный формат конфигурации скриптов.

**Status:** resolved (commit 9965d2e)

- [x] Штатная процедура доставляет и обновляет нужные исполняемые инструменты и systemd units; инструкция не предполагает неописанный checkout на сервере.
- [x] Пользователь сервиса, права на инструменты и конфигурацию, расположение rclone-настроек и доступ к remote согласованы и документированы.
- [x] После установки проверены ручной запуск unit, появление удалённых объектов, активный timer и время следующего запуска.
- [x] Ошибка dump, архивации, доступа к хранилищу или upload приводит к ненулевому завершению; лог не объявляет успех после частичного сбоя.
- [x] Проверочное восстановление допускает заявленный запуск без аргумента; обращение к отсутствующему аргументу не прерывает процедуру.
- [x] SQL-восстановление останавливается при ошибке, настройки пользователя/БД не противоречат дампу, отсутствие фото не выдаётся за полный успешный drill.
- [x] Временная БД изолирована от рабочей, имя уникально, контейнер и его временные volumes очищаются после успеха и неуспеха.
- [x] Изолированный сценарий на чистой установке и сценарии отказов проверены; согласование БД/фото в одну точку и полный запуск восстановленного приложения развиваются в следующем тикете.
