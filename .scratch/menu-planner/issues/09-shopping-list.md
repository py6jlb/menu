# 09: Список покупок

**What to build:** Пользователь получает список покупок из блюд недели: ингредиенты объединены по нормализованному названию (нижний регистр, трим), количества масштабируются коэффициентом «порции в плане / порции рецепта», единицы конвертируются внутри групп (вес г/кг, объём мл/л, штуки). Смешанные бытовые меры (стакан, ложка) остаются отдельной строкой без конвертации. Дробные количества показываются как есть (0.5, 1.5).
