# 07: Подбор блюд с фильтрами

**What to build:** При выборе рецепта в слот недели пользователь видит список блюд, отфильтрованных по жёстким фильтрам (исключают неподходящее: сложность, калорийность, сезонность, диета, ингредиенты) и ранжированных по мягким предпочтениям.

- [ ] Фронт: панель фильтров при выборе блюда в слот
- [ ] Юнит-тесты: логика жёстких фильтров и ранжирования
