# 16: Read-only режим для неподтверждённого (бэкенд)

**What to build:** Backend гарантирует read-only для пользователей с неподтверждённой почтой: просмотр разрешён, write-операции возвращают 403. Запрещено: создание/редактирование/удаление рецептов, изменение плана, создание/вступление в семью. Подтверждение почты (ввод кода, resend) — исключение, всегда доступно.

**Blocked by:** 12 (Миграция на .NET 10), 15 (Подтверждение почты (бэкенд))

**Status:** ready-for-agent

- [ ] 403 на write-операции (рецепты, план, семья) для неподтверждённого
- [ ] Подтверждение почты (ввод кода, resend) не блокируется
- [ ] Интеграционные тесты read-only
