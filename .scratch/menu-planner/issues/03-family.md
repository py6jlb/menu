# 03: Семья

**What to build:** Пользователь создаёт семью, получает инвайт-код, другой пользователь вступает по коду. Не более одной семьи на пользователя. Создатель = владелец (управляет составом), остальные — участники. Члены семьи видят общее пространство.

**Blocked by:** 02 (Аутентификация)

**Status:** ready-for-agent

- [ ] Создание семьи, генерация инвайт-кода
- [ ] Вступление по инвайт-коду, ограничение «не более 1 семьи на пользователя»
- [ ] Владелец может удалять/приглашать участников
- [ ] API отдаёт семью текущего пользователя и её участников
- [ ] Фронт: создание/вступление в семью, просмотр участников
- [ ] Интеграционный тест: создание семьи → вступление второго пользователя
