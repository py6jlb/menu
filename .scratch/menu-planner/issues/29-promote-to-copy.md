# 29: Промоушен внешнего рецепта в копию

**What to build:** Кнопка «Сделать копию» (на внешнем рецепте и на баннере предупреждения) превращает внешний рецепт в обычный редактируемый на месте: id сохраняется, записи плана не рвутся, файл фото копируется в собственное имя, пометка «скопировано из семьи X» сохраняется и стирается при редактировании.

**Blocked by:** 27 (Добавление внешнего рецепта в свою семью), 28 (Состояния «отозвана»/«сломана»)

**Status:** resolved (commit d25bb1a)

- [x] `POST /api/recipes/{id}/copy` превращает обёртку в обычный рецепт семьи (id сохраняется, записи плана продолжают ссылаться на него)
- [x] Файл фото копируется (своё имя в `photos/`); удаление/отзыв у источника больше не влияет на копию
- [x] После промоушена рецепт редактируется/удаляется как обычный; метка происхождения сохраняется и удаляется при редактировании
- [x] Кнопка «Сделать копию» доступна на внешнем рецепте и в баннере предупреждения; для сломанного рецепта (источник удалён) копия невозможна
- [x] Flow-тесты через `ApiFactory` покрывают промоушен, сохранение записей плана и копирование файла фото
