# 67: Проверка настоящего изображения при загрузке

**What to build:** Пользователь загружает действительное поддерживаемое изображение; поддельный MIME, повреждённый файл и чрезмерные размеры отклоняются понятно, не заменяя прежнее фото и не исчерпывая ресурсы обработки.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Проверяются фактический формат и декодирование, а не только присланный ContentType/расширение; содержимое, не являющееся изображением, отклоняется.
- [ ] Сохранены поддерживаемые пользовательские форматы либо явно описана совместимая обработка; тип выдачи соответствует фактически сохранённому содержимому.
- [ ] Ограничены размер входного файла, размеры/пиксели и ресурсы декодирования; очень большое изображение малого файлового размера не обходит защиту.
- [ ] Если применяется перекодирование/удаление metadata, поведение явно задано и не портит поддержку согласованных форматов, ориентацию и отображение.
- [ ] Отказ не меняет ссылку БД и не удаляет предыдущее фото; частичные временные файлы очищаются.
- [ ] UI сообщает ограничение до загрузки, отображает окончательный серверный отказ и допускает другой выбор без потери рецепта.
- [ ] Тестовые фото — реальные валидные изображения; проверены текст с image MIME, повреждённое изображение, mismatch формата, чрезмерные dimensions и успешная загрузка/выдача.
