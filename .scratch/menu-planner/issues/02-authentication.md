**Blocked by:** 01 (Инфраструктура и сборка)

- [ ] Вход: выдача JWT, проверка пароля
- [ ] Защищённый endpoint доступен только с валидным токеном
- [ ] Роли User/Admin в модели пользователя
- [ ] Фронт: регистрация, вход, logout, защита маршрутов
- [ ] Интеграционный тест: регистрация → вход → доступ к защищённому ресурсу
