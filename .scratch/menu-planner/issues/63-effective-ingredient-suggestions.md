# 63: Актуальные ингредиенты внешних рецептов без лишней загрузки

**What to build:** Семейное автодополнение предлагает названия из текущих ингредиентов собственных и доступных внешних рецептов, не требует загрузки всех шагов и сохраняет ограниченную, устойчивую выдачу.

**Blocked by:** 60 — Единое актуальное чтение рецепта для списка и деталей.

**Status:** ready-for-agent

- [ ] Серверное автодополнение использует проекцию единого модуля чтения, не самостоятельное смешивание старого fallback и источников.
- [ ] Правки источника видны при следующем запросе; warning учитывается, broken не даёт устаревших ингредиентов.
- [ ] Нормализация trim/lowercase, поиск по префиксу, ранжирование по частоте и затем названию, ограничение до десяти различимых подсказок сохранены.
- [ ] Фильтрация и ограничение реализованы так, чтобы не загружать полное содержимое семейной коллекции; не добавлено по запросу на каждый внешний рецепт.
- [ ] Пустой q возвращает топ, пользователь без семьи — пустой ответ; чужие семейные ингредиенты не раскрываются.
- [ ] Контракт остаётся совместимым с ручным вводом и стабильными строками frontend; не вводится обязательный глобальный справочник продуктов.
- [ ] Проверены актуализация источника, warning/broken, одинаковые имена, частота и семейная изоляция; измерены SQL-count/объём на представительном наборе.
