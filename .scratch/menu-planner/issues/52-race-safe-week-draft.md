# 52: Недельный черновик, устойчивый к поздним ответам и сетевым ошибкам

**What to build:** Участник редактирует план на неделю, переключает недели и сохраняет изменения без потери более новых правок от позднего ответа. При сетевом сбое черновик остаётся доступным, операцию можно повторить.

**Blocked by:** None (can start immediately)

**Status:** resolved (ticket/52-race-safe-week-draft)

- [x] Lifecycle недельного черновика сосредоточен вокруг identity недели, актуального draft и подтверждённого snapshot; изменение интерфейса не требует знать порядок ответов.
- [x] Ответ загрузки применяется только к актуальному запросу выбранной недели; обратный порядок GET не показывает чужую неделю под текущим заголовком.
- [x] Сохранение фиксирует неделю и отправленный snapshot; ответ не уничтожает правки, сделанные после отправки, и не отмечает другую неделю сохранённой.
- [x] Если редактирование во время сохранения блокируется, это явно отражено в UI; если разрешено, более новые правки сохраняются как dirty.
- [x] Network/timeout/parsing errors завершают pending в finally, дают русское сообщение и не очищают черновик; мутация с неизвестным результатом не повторяется автоматически.
- [x] Сбой загрузки подбора не препятствует загрузке самого плана; пользователь видит ошибку соответствующей операции.
- [x] Внутренняя навигация, Back, обновление и выход предупреждают при реальных несохранённых изменениях; успешная загрузка не создаёт ложный dirty.
- [x] Введена минимальная воспроизводимая основа frontend-тестов поведения; проверены управляемые обратные ответы, смена недели во время PUT, правка во время PUT, сетевой отказ и отмена ухода.

## Evidence

- Жизненный цикл вынесен в `frontend/src/composables/useWeekDraft.js`: `weekStart` + `draft` + `confirmedSnapshot`, привязка каждого ответа к неделе и номеру запроса, `finally` для pending.
- `frontend/src/views/PlanView.vue` использует composable; добавлены `onBeforeRouteLeave` (Back/внутренняя навигация) и `beforeunload` (обновление/выход); сбой подбора показывается отдельно и не блокирует план.
- Тесты: `frontend/src/composables/useWeekDraft.test.js` — 15 тестов (управляемые обратные ответы GET, смена недели во время PUT, правка во время PUT, сетевой отказ load/save, parsing, отмена ухода, отсутствие ложного dirty).
- Команды: в контейнере `node:24-alpine` — `npm test` (15 passed), `npm run build` (успешно).
- Редактирование во время сохранения разрешено: слоты активны, кнопка сохранения дизейблится на время PUT, более новые правки остаются dirty.
- Ограничение: тайм-аут HTTP реализуется клиентом на уровне `fetch` (в проекте таймаутов нет и не добавлялись); любое отклонение промиса (в т.ч. таймаут) обрабатывается общим `catch`.
