# 64: Стандартные диеты, одинаково работающие в форме и подборе

**What to build:** Пользователь выбирает стандартную диету по русскому названию в рецепте и находит его тем же фильтром подбора. Старые русские значения и произвольные пользовательские метки не исчезают при обновлении.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Стандартные диеты имеют единые канонические коды и русские подписи; форма, жёсткие фильтры и мягкие предпочтения используют один смысл значений.
- [ ] Форма предлагает стандартный выбор и сохраняет возможность произвольных меток отдельно от фиксированных кодов.
- [ ] Известные русские варианты существующих стандартных диет нормализуются предсказуемо; неизвестные значения сохраняются, не удаляются и не переводятся по догадке.
- [ ] Совместимость охватывает чтение/редактирование старых рецептов и живой контент внешних источников, без изменения чужого владения.
- [ ] Создание → чтение → редактирование → подбор сохраняет каноническое значение; выбор «Вегетарианское» совпадает со стандартным фильтром.
- [ ] Нормализация повторяема и не порождает дубли после второго сохранения; правила меток и кодов задокументированы.
- [ ] Проверены старые русские, новые кодовые, смешанные и произвольные значения, несколько диет и предпочтения.
