# 27: Добавление внешнего рецепта в свою семью

**What to build:** Участник семьи, открывший ссылку, нажимает «Добавить в мою семью» — в списке его семьи появляется «внешний» рецепт с пометкой источника («из семьи X»). Открывается на живой просмотр; редактирование, удаление и загрузка фото недоступны. Дубликат блокируется с переходом на существующий; без семьи — направление в создание семьи; из семьи-источника кнопки нет. Список фильтруется «все/свои/внешние». При добавлении показывается предупреждение, что рецепт может быть потерян при удалении у владельца.

**Blocked by:** 25 (Шаринг рецептом по ссылке), 26 (Просмотр рецепта по ссылке)

**Status:** resolved (commit b102c310cb8b7f19b749b80c4c38e687f7fb1163)
