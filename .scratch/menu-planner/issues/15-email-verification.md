# 15: Подтверждение почты (бэкенд)

**What to build:** Полный backend-поток подтверждения почты кодом. При регистрации создаётся аккаунт, сразу отправляется код, пользователь залогинен с `isEmailVerified=false`. Endpoint подтверждения (проверка кода), повторная отправка с таймером (дефолт 5 минут, настраивается в конфиге), лимит 5 неверных попыток → блокировка операции (`LockedUntil = now + 3 дня`, настраивается), rate limit 5 запросов/час на email + на IP.

**Blocked by:** 12 (Миграция на .NET 10), 14 (Модель AuthCode и поля User)

**Status:** ready-for-agent

- [ ] При регистрации — отправка кода подтверждения
- [ ] `POST` проверки кода подтверждения (одноразовый, проверка лимита попыток)
- [ ] Повторная отправка с таймером (дефолт 5 мин, настраивается в конфиге)
- [ ] 5 неверных попыток → `LockedUntil` (дефолт 3 дня, настраивается)
- [ ] Rate limit: 5/час на email + на IP
- [ ] Интеграционные тесты подтверждения
