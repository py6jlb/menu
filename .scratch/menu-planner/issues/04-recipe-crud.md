# 04: CRUD рецептов

**What to build:** Пользователь создаёт, редактирует, удаляет и просматривает рецепты семьи. Полная модель: название, описание, шаги приготовления, время, порции, сложность, калорийность (вручную), сезонность (несколько), диеты (несколько), теги. Ингредиенты: название (свободный текст) + число + единица из справочника + примечание. Рецепт принадлежит семье, редактировать/удалять могут все члены.
