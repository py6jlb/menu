# 69: Настройки без побочных эффектов чтения

**What to build:** Пользователь читает значения личных настроек по умолчанию без создания записи, изменяет их предсказуемо и может повторить действие после сетевого сбоя или конфликтующего первого сохранения.

**Blocked by:** 37 — Проверка критических гарантий на PostgreSQL.

**Status:** ready-for-agent

- [ ] GET отсутствующих настроек возвращает defaults и не записывает БД; повторное чтение не создаёт запись и не конфликтует с другим читателем.
- [ ] Явное сохранение создаёт/обновляет настройки, обрабатывает конкурентную первую вставку при уникальности пользователя без необработанного 500.
- [ ] Диапазон окна повторяемости и изоляция пользователя сохранены; неподтверждённая почта читает, но не меняет настройки.
- [ ] UI отличает загрузку, изменение и сохранение; network/parsing failures завершают pending, сохраняют введённое и дают понятный повтор.
- [ ] Ответ более старой операции не уничтожает последующую правку; подтверждённое сохранение отражает фактическое серверное значение.
- [ ] Проверены отсутствующая запись, повторные GET без записи, два первых сохранения на PostgreSQL, валидация и отказ сети в интерфейсе.
