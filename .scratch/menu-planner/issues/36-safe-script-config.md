# 36: Единый безопасный формат конфигурации скриптов

**What to build:** Оператор может использовать один документированный способ конфигурации сборки, деплоя и резервного копирования: значения с пробелами и специальными символами читаются буквально, не превращаются в команды и не прерывают запуск.

**Blocked by:** None (can start immediately)

**Status:** claimed (ticket/36-safe-script-config; ожидает итогового code-review)

Реализация и изолированные проверки подготовлены в worktree; доказательства критериев и TDD red/green — `deploy/tests/README.md`. Чеклист оставлен для итогового ревью основным агентом.

- [ ] Выбран и документирован безопасный формат конфигурации; её содержимое не исполняется как shell-код. Поведение согласовано с чтением окружения Docker Compose.
- [ ] Настройки локальной публикации и серверного запуска явно разделены; секреты сервера не доставляются вместе с публичными конфигурациями.
- [ ] Все потребители конфигурации используют согласованный способ чтения; отсутствие необязательного файла не ломает запуск с переменными окружения.
- [ ] Документирован приоритет переменных окружения и файла; обязательные отсутствующие значения приводят к понятной ошибке до внешних действий.
- [ ] Штатный шаблон, русское имя отправителя, пробелы, `$`, `#`, кавычки и обратные слеши читаются без неожиданного изменения значения.
- [ ] Проверка с содержимым, похожим на shell-команду или подстановку, подтверждает отсутствие исполнения; секреты не выводятся в диагностике.
- [ ] Проверки чтения конфигурации выполняются изолированно, без реального деплоя, отправки писем или записи в объектное хранилище.
