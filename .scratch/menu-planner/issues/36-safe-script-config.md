# 36: Единый безопасный формат конфигурации скриптов

**What to build:** Оператор может использовать один документированный способ конфигурации сборки, деплоя и резервного копирования: значения с пробелами и специальными символами читаются буквально, не превращаются в команды и не прерывают запуск.

**Blocked by:** None (can start immediately)

**Status:** resolved (commit 91886d5)

- [x] Выбран и документирован безопасный формат конфигурации; её содержимое не исполняется как shell-код. Поведение согласовано с чтением окружения Docker Compose.
- [x] Настройки локальной публикации и серверного запуска явно разделены; секреты сервера не доставляются вместе с публичными конфигурациями.
- [x] Все потребители конфигурации используют согласованный способ чтения; отсутствие необязательного файла не ломает запуск с переменными окружения.
- [x] Документирован приоритет переменных окружения и файла; обязательные отсутствующие значения приводят к понятной ошибке до внешних действий.
- [x] Штатный шаблон, русское имя отправителя, пробелы, `$`, `#`, кавычки и обратные слеши читаются без неожиданного изменения значения.
- [x] Проверка с содержимым, похожим на shell-команду или подстановку, подтверждает отсутствие исполнения; секреты не выводятся в диагностике.
- [x] Проверки чтения конфигурации выполняются изолированно, без реального деплоя, отправки писем или записи в объектное хранилище.
